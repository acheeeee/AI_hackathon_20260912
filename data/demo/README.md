# 虛構案件展示檔

這個資料夾內的兩份 PDF 是同一件完全虛構的測試案件。所有姓名、地址、統一編號、文號、日期、附件與事實均為展示用途；不得作為法律文件或對外行文。

## 上傳順序

1. 「訴願書」上傳 `展示用_虛擬資產服務登記_訴願書.pdf`。
2. 「行政處分函」上傳 `展示用_虛擬資產服務登記_行政處分函.pdf`。
3. 建立案件後，檢查擷取欄位、案件相關關鍵字、行政處分函摘要與建議法規查詢關鍵字。
4. 在程序審查檢查各款來源：送達日、書面提出方式及文件明載的程序事實會自動帶入，第2至8款預期未觸發。
5. 展開第1款「補充／修改判定資料」，核對訴願書後將「訴願書是否欠缺法定程式」選為「否」，按「儲存並重新判定」；第一款轉為未觸發。此欄不得只因文件有文字就自動假設符合。
